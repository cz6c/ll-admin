## 价值观（决策滤镜）

改 UI / 交互时用这四条判断「该不该做」：

1. **自然**：视觉与行为符合用户既有认知；少打断、少强迫记忆。
2. **确定性**：克制、模块化、跨页一致；能复用 `FormView` / `ToolButtons` / `feedback` / `card-*` 就不新造一套。
3. **意义感**：每个操作服务任务目标；有结果就要有反馈；勿为装饰分散注意力。
4. **生长性**：新功能可发现，但不靠漫游引导掩盖糟糕信息架构。

5.0 视觉方向（MasterGo / 官方 5.0）：**更聚焦、去干扰、轻松感**——少多层阴影与装饰边框，用留白与字重分层。

## 布局与模度

- 网格基数 **8**；布局尺寸尽量 **8 的倍数**。
- 内容区按 **24 栅格** 思路做响应（`a-row`/`a-col` 或等价 Grid）；Gutter 用固定档位（常用 8/16/24），勿随手改。
- 左右布局：侧栏固定、主工作区伸缩（本仓 Sidebar + 内容区已是此模式，勿改成「整页一起挤扁导航」）。
- 区块容器：Uno `card-panel` / `card-section` / `card-meta`；圆角 **8** / 内嵌 **6**（`radius-card` / `radius-inner`）。
