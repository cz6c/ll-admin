## 原则 6 · 足不出户

能在本页解决就不要跳页刷新，避免打断心流。

| 模式 | 用法 | Admin 映射 |
|------|------|------------|
| 覆盖层 | 详情 Popover、少量字段输入、不可撤销用 Popconfirm | `a-popover` / `a-popconfirm`；悬停激活约 **0.5s** 延迟，移出立即关 |
| 嵌入层 | 列表展开行、Tabs 分组 | 详情/设置用 Tabs；勿为平级信息连环开页 |
| 流程 | 渐进展现、配置向导 | 复杂流程可用 Modal 内 Steps，仍尽量同页 |

- **删除等可撤销操作**：优先直接执行 + Message「撤销」，勿滥用 Modal 二次确认（狼来了）。
- **不可撤销**：当前页 `Popconfirm` / 明确确认，仍避免无上下文的大 Modal 打断。
