## 原则 1 · 亲密性

关联越高越近，越像一个视觉单元。

| 档位 | 值 | 用途 |
|------|-----|------|
| 小 | **8px** | 图标↔文案、标签↔控件、组内紧邻 |
| 中 | **16px** | 同组表单项、工具栏↔表格、卡片内区块 |
| 大 | **24px** | 页边、查询区↔列表、卡片↔卡片 |

- 纵向尽量 `y = 8 + 8n`（`n >= 0`）。Uno 用 `gap-8px` / `16` / `24`；**禁止**随意 13/15/18（现有 shortcut 如 `py-14px` 除外）。
- 三档不够：加减 8 的倍数，或加 **分割线** 拉开层次。
- 组件内部间距 < 组件之间间距。
