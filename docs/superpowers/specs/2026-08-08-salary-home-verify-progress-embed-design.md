# 首页：核对入口与进度同组（方案 A）

## 问题

原顺序「月薪核对 → 年薪测算 → 本年进度」把进度与核对入口割裂。方案 C（进度嵌进主卡）落地后视觉拥挤、入口歧义，已撤回。

## 决策

采用方案 A：核对入口与本年进度同组紧贴；年薪测算下沉为次级卡。

```
Hero
┌ 核对模块（verify-group，组内 gap 12rpx）─┐
│ 月薪核对主卡（整卡点击进核对）            │
│ 本年进度卡（独立浅底面板，紧贴下方）      │
└──────────────────────────────────────────┘
年薪测算（次卡，与组间距 16rpx）
```

| 项 | 约定 |
|----|------|
| 月薪核对卡 | 整卡进 `/pages/salary/verify`；有记录时 hint「见下方进度」 |
| 进度卡 | 独立组件，含图例 / 月格 / 摘要 CTA；不嵌进入口卡 |
| 「核对记录」 | `/pages/salary/history?tab=verify` |
| 测算卡 | 整卡进测算；视觉次级 |

## 不改

- `buildYearVerifyProgress`、月格语义、CTA 去向
- 测算页 / 详情页能力
